## Interfaces do sistema original

Devido a limitações de acesso ao sistema original e à indisponibilidade dos registros visuais
utilizados durante a avaliação, não foi possível disponibilizar as imagens da interface atual.

Ressalta-se que a análise de usabilidade foi conduzida in loco, com base na observação direta
das interações dos usuários, sendo os problemas identificados descritos e sistematizados
nos documentos deste repositório e no texto do TCC.
