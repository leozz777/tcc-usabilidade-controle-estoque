# TCC – Avaliação de Usabilidade de Sistema de Controle de Estoque

Este repositório contém o material complementar do Trabalho de Conclusão de Curso
intitulado **“Proposta de melhoria de usabilidade de um sistema de controle de estoque para um comércio”**.

## Objetivo

Disponibilizar materiais de apoio relacionados à avaliação de usabilidade realizada,
incluindo imagens das interfaces analisadas, registros dos problemas identificados
e as soluções propostas com base nas heurísticas de Nielsen e na norma ISO 9241-110.

## Conteúdo do repositório

- `/imagens-interface-atual`: capturas de tela do sistema original, com foco nos problemas de usabilidade.
- `/imagens-prototipo`: imagens do protótipo de alta fidelidade desenvolvido no Figma.
- `/avaliacao-heuristica`: descrição resumida dos problemas encontrados e das soluções propostas.
